# Запоминание данных входа

В PROD- и DEV-лаунчерах справа от пароля доступна галочка «Запомнить данные».
По умолчанию она выключена. После успешного входа или регистрации с галочкой
логин и пароль сохраняются в `%LOCALAPPDATA%\REvolutionClient\remembered-login.bin`
для PROD и `%LOCALAPPDATA%\REvolutionClientDev\remembered-login.bin` для DEV.
Оба поля зашифрованы Windows DPAPI (CurrentUser). Открытого пароля и токенов в файле нет.

При следующем запуске поля и галочка восстанавливаются. Для входа нужно нажать
«Войти»; автоматический вход и запуск игры не выполняются.
Снятие галочки сразу удаляет сохранение, сохраняя текущие поля формы.
Если удаление не удалось, галочка возвращается и появляется предупреждение.
Повреждённый или недоступный для расшифровки файл не препятствует ручному входу.
Ошибка сохранения не отменяет уже выполненный вход, но показывает предупреждение.

Профили используют отдельные файлы сохранённых данных. Хранилище не зависит
от папки игры и `launcher-settings.json`.

Проверка (Windows, вымышленные данные, без подключения к auth/запуска игры):

```powershell
dotnet run --project tools/LauncherCheck -p:LauncherChannel=Dev -- --remember-login
dotnet run --project tools/LauncherCheck -p:LauncherChannel=Prod -- --remember-login
```
