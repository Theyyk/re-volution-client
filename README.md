# RE:volution Client

Private client distribution for RE:volution.

This repository owns the Windows launcher, the client-only Minecraft Forge 1.12.2 mod, update manifests, client distribution resources, and build/release automation.

The public gameplay mod is maintained separately in `Theyyk/re-volution-mod` and is intentionally not modified by this project.

## Release target

The first production-ready release target is **RE:volution Client v1.0.0**.
